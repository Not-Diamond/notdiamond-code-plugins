# Not Diamond Code plugins

A plugin marketplace for Claude Desktop running on Not Diamond Code.

## connectors

Lists common hosted connectors so you can sign in to the ones you use: Linear, Notion, Atlassian, Sentry, Intercom, monday.com, Canva, Figma, PostHog, Vercel, Stripe, Attio and Cloudflare.

Each connector points at the vendor's own MCP server. Sign-in happens with the vendor, and this repository holds no credentials.
